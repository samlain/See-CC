# See-CC
See CC is an interactive, Java-based game designed to promote campus engagement and community exploration. Developed by Tori Zhu, Oliver Moscow, Evelyn Needham, and Samuel Lain for a college course project, the game was built using object-oriented design principles and the Model-View-Controller (MVC) architecture. The project was created in response to the challenge that college students often feel isolated or disconnected due to busy schedules, lack of familiarity with their surroundings, or limited social engagement. See CC offers a playful and rewarding way to explore the Colorado College campus virtually.

At the start of the game, new users can sign up by entering their name, major, username, and selecting a character icon. Returning players can log in with their previous username, and their points and progress are saved through MySQL database integration. The player moves through the campus using arrow keys on the keyboard, exploring different buildings represented on a central map. When the player approaches a building, a button appears prompting them to enter. Once inside, they can talk to NPCs who provide fun facts and insights about campus life, or play one of several minigames tied to that building.

Each minigame has multiple difficulty levels, awarding different amounts of points based on performance. For example, players can earn points in the gym or library and later use them to gamble in the slot machine game at Rastall’s (Rasties), which has specific point requirements before placing bets. The game keeps track of player progress and points, and a leaderboard is accessible from the main map to show player rankings from highest to lowest. Clicking the leaderboard button toggles between the rankings view and returning to the main map.

See CC combines learning, exploration, and fun through structured gameplay, unique characters, and interactive challenges. It leverages Java Swing for the GUI, MySQL for persistent player data, and a modular codebase that separates logic into player, map, building, NPC, game, and save components. This project demonstrates collaborative software design and the practical application of databases, user input handling, and dynamic UI updates to create a meaningful experience for students navigating campus life.
